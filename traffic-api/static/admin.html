확인한 뉴스 저장

직접 저장 버튼을 누른 경우에만 저장을 요청합니다.

1. 뉴스 초안 생성

교통정보 분석 후 OpenAI API가 기사를 작성합니다. 생성 전 API 이용 요금이 발생할 수 있습니다.

아직 생성된 기사가 없습니다.

2. 뉴스 미리보기 및 검토

조회된 실제 경로 정보와 기사 문구를 확인하세요. 초안 생성 전에는 미리보기가 표시되지 않습니다.

3. 검토 후 저장

기사와 경로별 수치를 검토한 경우에만 저장하세요. 초안 생성만으로는 Supabase에 저장되지 않습니다.

4. 기사 발행 관리

새로 저장된 기사는 검토 중으로 비공개입니다. 관리자가 발행해야 뉴스 페이지에 표시됩니다. 기존 기사는 공개 상태를 유지합니다.

목록을 불러오려면 버튼을 누르세요.

운영 설정·공지

현재 서버에 적용된 운영 정책을 확인하는 읽기 전용 안내입니다. 이 화면에서 환경변수나 자동 수집 설정을 변경하지 않습니다.

정기 수집 — 비활성. 수집 이력 조회만 가능하며, 자동 실행은 별도 검증·승인 후 활성화합니다.
기사 공개 정책 — 신규 기사는 검토 중(비공개)으로 저장합니다. 관리자가 발행한 기사만 공개됩니다. 기존 기사는 기존 공개 상태를 유지합니다.
장애 알림 — 관리자 화면에서 수동 확인합니다. 이메일·메신저 등 외부 알림은 비활성입니다.
API 사용 통계 — 서버 프로세스별 참고용 집계이며, 카카오 공식 요청 한도·과금 정보가 아닙니다.

서비스 공지는 이 운영 안내를 통해 제공하며, 공개적인 공지 게시·편집 기능은 아직 제공하지 않습니다.

정기 수집 현황

수집 처리기만 준비됐으며 실제 자동 실행은 비활성입니다. 수동 확인은 기존 기록만 조회합니다.

수집 이력을 조회하려면 버튼을 누르세요.

운영 오류 기록

실패 유형과 시각만 저장합니다. 출발지·목적지, API 키, 응답 본문은 기록하지 않습니다. 외부 알림은 사용하지 않습니다.

버튼을 누르면 최근 오류 기록을 확인합니다.
